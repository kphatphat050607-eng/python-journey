# Week 36 — Class DienThoai

## Mục tiêu
- Ôn tập class và object trong Python.
- Khai báo thuộc tính bằng `__init__()`.
- Viết phương thức để hiển thị thông tin object.
- Tạo hai object điện thoại và in thông tin ra màn hình.

## Bài tập

Tạo class `DienThoai` gồm các thuộc tính:
- `MaMay`
- `TenMay`
- `HangSanXuat`
- `DungLuongPin`
- `GiaBan`

Tạo phương thức:
- `__init__()`: khởi tạo 5 thuộc tính.
- `thongtindienthoai()`: hiển thị đầy đủ thông tin điện thoại.

Tạo hai object:
1. `DienThoai("DT01", "iPhone 15 Pro", "Apple", 3274, 28990000)`
2. `DienThoai("DT02", "Galaxy S24 Ultra", "Samsung", 5000, 29990000)`

Gọi phương thức `thongtindienthoai()` cho từng object và in kết quả.
